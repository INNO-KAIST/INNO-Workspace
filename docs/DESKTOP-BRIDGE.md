# 데스크톱과 클라우드 작업 연결

## 이번에 가능한 흐름
클라우드 INNO에서 첨부 없는 작업을 만들거나, 데스크톱 연결 화면에서 같은 작업에 원본을 재연결한 뒤 Codex를 선택하여 실행하면, 켜져 있는 데스크톱 연결기가 작업을 가져옵니다. 답변과 생성 결과는 같은 클라우드 작업에 저장되어 휴대폰에서도 확인할 수 있습니다. 기존 로컬 전용 작업 기록은 그대로 별개로 보존됩니다.

## 실행
프로젝트의 `Start INNO Workspace.cmd` 또는 `Start INNO Cloud Bridge.cmd`를 실행합니다. 이어서 프로젝트의 `.inno/DESKTOP-ACCESS.md`에 있는 개인 접속 링크를 엽니다. 별도 인증값 입력은 필요 없습니다. 기존 로컬 전용 모드는 `Start INNO Local Only.cmd`로 보존했습니다. Node.js 24와 ChatGPT 구독으로 로그인한 Codex가 필요합니다. 현재 Codex 앱 터미널에서는 `node scripts/desktop-bridge.mjs`로 실행할 수 있습니다. 기존 `.inno/cloud-access-token.txt`를 사용하며 키를 다시 입력할 필요는 없습니다. Ctrl+C로 중지합니다. 중복 실행은 로컬 잠금으로 차단됩니다.

원본 협업 하위 작업은 시작 시 프로세스 환경변수 `INNO_SOURCE_DELEGATION_VERSION`이 정확히 문자열 `1`일 때만 데스크톱에서 지원을 알립니다. PowerShell에서 시험할 때는 실행 전에 `$env:INNO_SOURCE_DELEGATION_VERSION='1'`을 설정하고 위 Node 명령으로 연결기를 시작합니다. `.cmd` 실행기도 시작한 셸의 환경을 상속합니다. 이미 실행 중인 연결기는 환경 변경을 반영하지 않으므로 정상 종료한 뒤 다시 시작해야 합니다. 되돌릴 때는 연결기를 종료하고 `Remove-Item Env:INNO_SOURCE_DELEGATION_VERSION -ErrorAction SilentlyContinue` 후 다시 시작합니다. 값이 없거나 `1` 이외이면 지원 버전은 0입니다. 서버도 별도로 같은 버전을 지원해야 하며, 실제 실행에는 양쪽 capability의 교집합만 사용합니다. 현재 운영 설정을 이 안내만으로 변경하지 않습니다.

휴대폰은 기존 클라우드 URL, 데스크톱은 위 개인 접속 링크를 사용하면 같은 클라우드 작업 기록을 봅니다. 데스크톱 화면에서 작업을 선택하고 파일 또는 폴더를 연결한 뒤 Codex 실행을 누르세요. 원본 내용은 로컬 Codex에만 일시 전달되며, 클라우드에는 참조 메타데이터와 생성 결과만 저장됩니다. 파일이 바뀌거나 연결이 끊겼으면 재연결해야 합니다. 로컬 전용 화면에서 생성한 작업의 자동 이전은 아직 하지 않습니다. PC가 꺼져 있을 때 Codex 요청은 대기하며, Claude 클라우드 실행은 별도로 사용할 수 있습니다.

## 효율성과 보존
- 실행은 데스크톱 한 개당 하나씩 수행합니다. 대기 조회는 유휴 시 15~60초 간격으로 늦춰집니다.
- 대기열 상태 인덱스로 전체 작업·첨부·결과를 반복 내려받지 않습니다.
- 실행권은 15초마다 확인·갱신합니다. 사용자 중지와 실행권 상실 시 로컬 실행에 중지를 전달합니다.
- 완료 응답 유실 시 `.inno/desktop-pending.json` 한 건을 재전송합니다. 완료 응답을 확인한 대기 기록만 제거합니다.
- 429/서버 오류/일시 연결 오류는 최대 60초 간격으로 재시도합니다. 인증·소유권 등 영구 오류는 중지합니다.
- 생성 파일은 `.inno/desktop-runs`에 보존합니다. 저장량 256 MiB 또는 항목 5,000개를 넘으면 새 작업 수신을 멈춥니다. 사용자 결과를 임의로 지우지 않습니다.
- 원본 입력 내용은 대기열이나 재전송 파일에 보관하지 않습니다.

## 아직 남은 범위
- 실행 중 단절되어 결과 자체가 아직 만들어지지 않은 작업의 자동 재개. 현재는 일시정지 후 명시적으로 재개합니다. 이미 만들어져 전송 대기 중인 결과는 연결 회복 시 복구됩니다. 사용자 수정·취소·새 실행이 있으면 오래된 결과 복구를 차단합니다.
- PC 로그인 시 연결기 자동 시작은 아직 등록하지 않았습니다.

결과 전송이 700,000바이트를 넘으면 로컬 결과를 보존하고 전송을 멈춥니다. 대용량 생성 결과 전달은 후속 단계입니다.

## 자료 범위

기존 텍스트/PDF/DOCX/PPTX 추출기가 처리할 수 있는 자료를 사용합니다. 요청 전체 750,000바이트, 텍스트 전달 등 기존 한도는 유지됩니다. URL 링크만으로 본문을 읽었다고 처리하지 않습니다. 원문 파일을 연결해야 합니다. 폴더 내용 전체를 무제한 실행기에 전달하지 않습니다.

동일한 화면 상태는 5초 조회마다 목록을 다시 만들지 않아 불필요한 화면 갱신을 줄였습니다.

## 기존 로컬 기록 가져오기
**작업실 연결 → 기존 로컬 기록 선택**에서 필요한 기록을 클라우드로 가져올 수 있습니다. 원본 DB는 보존하고 중복은 건너뜁니다. [기록 통합 안내](RECORD-IMPORT.md)를 참고하세요.

## 시작 시 포트 사용 중 안내

4174는 중복 실행 방지용, 4175는 로컬 작업 화면용 포트입니다. 같은 실행 파일을 두 번 열면 두 번째 실행은 기존 프로세스를 유지하고 안내 후 종료됩니다. `.inno/DESKTOP-ACCESS.md` 링크로 기존 화면에 접속하세요. 접속되지 않는다면 INNO 외의 프로그램이 점유했거나 기존 연결이 시작 중일 수 있습니다. 포트 충돌만으로 기존 프로세스를 강제 종료하지 않습니다.
