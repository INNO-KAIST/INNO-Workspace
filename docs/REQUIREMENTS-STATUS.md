자료가 필요한 작업은 자동 실행기가 대기 상태를 바꾸거나 빈 원문으로 시작하지 않으며, 뒤의 자료 없는 작업은 계속 처리한다. 내부 설정을 켠 시험 환경에서 두 제공자의 하위 작업·마스터 검토에 원문을 일시 전달하는 경로를 연결했다. 전체371개 테스트 통과(제공자 모의 응답). 현재 기본 실행 환경은 비활성이며 계획 지침 연결·원본 재연결 UI·실제 구독 실행 검증은 남아 있다.

### 마스터 자료 배정 지침 연결

내부 기능 설정이 켜진 경우 Codex·Claude 마스터에 정제된 자료 ID/범위 참조와 원문 비보관 배정 지침을 전달한다. Codex 배정 결과의 미등록 자료 ID는 전달 전에 거절하며 서버 상태에서 지원 버전을 확인할 수 있다. 전체376개 테스트 통과(모의 제공자). 데스크톱 실행기와의 지원 버전 일치 및 브라우저 재연결 연결은 남아 있어 기본 기능은 계속 비활성이다.

### 데스크톱 지원 버전 확인

서버와 데스크톱 실행기가 공통으로 지원하는 첨부 협업 버전만 사용한다. 미지원 실행기는 첨부 하위 작업을 점유하기 전에 거절되며, 브라우저가 보낸 값으로 로컬 지원 범위를 높일 수 없다. 전체382개 테스트 통과. 실제 활성화 전 브라우저 자료 재연결·자동 전달·불확실한 시작 응답 복구가 남아 있다.

### 브라우저 자료 준비 공통화

일반 실행 버튼을 공통 자료 읽기·검증 경로에 연결했다. 읽기 전 개수/연결 상태를 확인하고 비동기 읽기 중 작업 버전이나 연결 서버가 바뀌면 전송하지 않는다. 실제 파일의 선택 범위·내용 변경 검증을 포함해 전체388개 테스트 통과. 하위 작업 자동 전달 조정 기능은 이 경로를 재사용하도록 이어서 구현해야 한다.
