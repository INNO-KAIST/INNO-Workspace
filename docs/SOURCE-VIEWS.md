# 자료의 필요한 범위만 조회하기

파일 미리보기의 **조회 범위 선택**에서 범위를 입력하고 **선택 범위 미리보기 → 이 범위 저장**을 누릅니다. 텍스트는 UTF-8 시작 바이트와 조회 길이, PDF는 시작·끝 페이지를 지정합니다. 입력을 바꾸면 다시 미리보기해야 저장할 수 있습니다. 선택 초기화로 기존 전체 추출 방식으로 돌아갑니다.

기록과 내보내기에는 파일 메타데이터, 선택 범위, 선택한 추출 텍스트의 SHA-256만 남습니다. 원문은 연결된 브라우저 파일에서 실행 시 다시 읽습니다. 같은 파일을 재연결하면 선택 범위를 유지하며, 선택 부분이 변경되었으면 실행을 중단하고 다시 선택하도록 안내합니다. 이 해시는 전체 파일의 변경 여부를 보장하지 않습니다.

- 텍스트 선택: 최대 200,000 원본 바이트. UTF-8 문자 경계에 맞춰 실제 범위를 표시합니다.
- PDF 선택: 연속 최대 100페이지, 기존 압축 파일 입력 한도 30MiB 유지. 내장 텍스트만 읽고 이미지·스캔 OCR은 지원하지 않습니다.
- 실행 자료: 최대 20개, 합계 UTF-8 600,000바이트. 임의 용량·형식의 무제한 지원이 아닙니다.
- 원본 연결을 잃으면 다시 연결해야 합니다. PC가 꺼진 동안 해당 PC 원본을 읽을 수 없습니다.
- 원본이 필요한 작업은 현재 제공자 간 내구성 있는 병렬 하위 작업으로 자동 전달하지 않습니다.
- AI 제공자에게 실행 자료를 일시 전달하는 과정은 존재하며, 제공자 자체 보존 정책까지 이 기능이 통제하지는 않습니다.

2026-09-21 로컬 검증: 전체 312개 테스트 통과. 791KB 합성 파일의 중간 구간 선택·정확한 텍스트 표시·입력 변경 시 이전 저장 차단·저장 및 390×844 화면 확인. 외부 AI 실행 및 운영 배포는 이번 자료 조회 검증에 포함하지 않았습니다.
