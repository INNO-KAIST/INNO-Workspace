# 병렬 마스터 실행과 복구

INNO Workspace는 외부 연구 앱 연결 없이 동작하는 독립 플랫폼입니다. 이 단계의 병렬 배정은 서로 독립적인 작업 두 개(각각 Codex와 Claude 하나)로 제한합니다. 단순한 요청은 마스터가 직접 처리합니다.

## 실행 흐름

1. 마스터가 요청과 필요한 결과·검증 기준을 먼저 해석합니다.
2. 지원 모델 목록에서 충분한 모델과 추론 강도를 선택하고 배정 이유를 기록합니다.
3. 서버가 부모·하위 작업과 실행권을 원자적으로 저장합니다. 같은 배정 응답의 재전송은 기존 작업을 반환합니다.
4. Codex는 연결된 데스크톱에서 실행하고 Claude는 기존 Routine에서 실행합니다. 데스크톱이 꺼져 있으면 Codex 하위 작업은 대기합니다.
5. 양쪽 결과가 완료되면 원래 마스터만 다시 실행해 모든 검증 기준을 확인합니다. 결과가 모였다는 이유만으로 완료 처리하지 않습니다.
6. 실패한 기준은 한 배치에 한 번만 추가 실행할 수 있습니다. 이미 완료한 다른 하위 결과와 과거 생성 파일은 보존합니다. 확인 불가 또는 재시도 소진은 사용자 결정으로 넘깁니다.

## 화면과 복구

작업 목록에는 부모 아래 하위 작업이 묶여 보입니다. 상세 패널에는 제공자·요청 모델·배정 이유·검증 기준·상태가 표시됩니다. 요청 모델 표시는 실제 서빙 모델 확인을 뜻하지 않습니다.

- 실패한 작업만 재시도하며, 하위 작업을 개별 일반 실행 버튼으로 다시 시작하지 않습니다.
- 한도나 연결 문제는 해결한 후 명시적으로 복구합니다. 자동으로 다른 계정·제공자로 우회하지 않습니다.
- 응답 유실 등으로 원격 실행 여부가 불확실하면 이전 실행이 종료됐는지 먼저 확인해야 합니다. 확인하지 않고 재시도하면 같은 작업에 토큰을 두 번 쓸 수 있습니다.
- 부모 일시정지·취소는 이후 결과 기록과 새 배정을 차단합니다. 외부 Claude 세션의 계산 자체를 즉시 중지하는 API는 구현되어 있지 않습니다. 이미 시작한 세션의 종료는 해당 세션에서 확인합니다.
- 새 요청은 이전 배정을 대체합니다. 과거 결과 기록은 유지하지만 기존 하위 실행이 새로운 요청을 완료할 수는 없습니다.

## 자료와 모델의 범위

원본 첨부가 있는 작업도 배정할 수 있습니다(서버와 데스크톱 실행기가 원본 협업 버전 1을 함께 지원할 때). 마스터는 이 작업의 첨부 중 각 하위 작업에 필요한 자료만 sourceIds로 지정하고 원문을 지시에 복사하지 않습니다. 원문은 실행 시점에 연결된 원본에서 선택 범위만 일시 조회하며 저장하지 않습니다. 원본이 연결되지 않으면 해당 실행은 재연결을 기다립니다. URL 참조는 원문이 아니므로 실행 전에 문서를 연결해야 합니다. 자세한 흐름은 SOURCE-VIEWS.md를 봅니다. 생성된 하위 결과는 최대 20파일/합계 5MB 범위의 검토 목록으로 전달합니다. Codex 검토 실행은 임시 실행 폴더에 선택된 생성 파일을 받고, Claude는 목록에서 필요한 하위 결과만 범위가 제한된 read_task로 조회합니다. 원문 영구 보관 기능을 추가하지 않습니다.

Codex 모델 목록은 계정에서 확인한 결과를 공유하고 최대 한 시간 간격으로 같은 내용을 갱신합니다. 두 시간 이상 오래된 목록으로 새 모델을 배정하지 않습니다. 모델 목록이 없으면 마스터 직접 처리 또는 데스크톱 재연결이 필요합니다.

Claude Routine의 마스터 모델은 기존 설정을 유지합니다. 하위 역할은 haiku/sonnet/opus 중 지정된 모델을 사용하도록 요청하지만 별도 Routine 마스터 비용이 있습니다. 역할의 정확한 서빙 모델이나 추론 강도 적용이 관측되지 않으면 확인됐다고 표시하지 않습니다. 토큰 절감률과 동일 품질을 보장하거나 추정값을 실제 관측값으로 표시하지 않습니다.

## 운영

완료 콜백이 다음 단계를 연결합니다. 5분 간격의 예약 복구는 최대 10개 항목을 순환 확인하며 모델을 폴링 도구로 사용하지 않습니다. 원격 실행 응답이 불확실하면 새 세션을 자동 생성하지 않습니다.

Claude는 payload에 받은 실행별 Capability를 최신 scripts/inno-mcp.mjs의 입력 JSON에 executionCapability로 전달합니다. helper가 JSON-RPC 봉투로 이동하며 명령줄 인수에는 넣지 않습니다. 완료된 실행은 완료 재전송만 허용하고 일반 조회·쓰기는 회수합니다. 5분 안에 renew_execution을 호출해 작업의 실행권을 갱신합니다.

이 범위 검사는 INNO MCP 도구의 작업 배정을 제한합니다. 기존 전용 환경의 호스트 인증은 동일 사용자 계정에 대한 신뢰를 전제로 하며, 임의의 악성 코드를 격리하는 네트워크 보안 경계를 뜻하지 않습니다.

일반 다단계 작업 그래프, 임의 개수의 병렬 에이전트(현재 Codex 1 + Claude 1 고정), 새 AI 제공자 추가(CR-006), 모든 구독 잔여량 자동 조회는 후속 범위입니다.
